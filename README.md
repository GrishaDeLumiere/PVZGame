# PVZ PLUS (Java)

Это клон популярной игры **Plants vs. Zombies (PVZ)**, полностью реализованный на **Java**. Игра называется **PVZ PLUS**, поскольку в будущем планируется добавление поддержки модов, что позволит расширить игровые механики и контент.

Изначально проект был создан в **Eclipse** с использованием **Gradle** (который до сих пор остался — настройте его самостоятельно), но в данный момент я перешел на **Visual Studio Code**, так как он более удобен для разработки.

## Реализованные компоненты:
- **GUI**: Реализован графический интерфейс пользователя для навигации и взаимодействия с игрой.
- **FONT**: Поддержка шрифтов для отображения текста в игре.
- **LEVEL**: Реализована структура уровней, включая логику сложности и прогресса.
- **SOUND**: Добавлены звуковые эффекты для различных событий в игре.
- **TEXTURE**: Текстуры для объектов игры, включая растения, зомби и фоны.
- **LOCALIZATION**: Механизм локализации, который позволяет добавить поддержку различных языков.
- **НАСТРОЙКИ**: Система настроек, позволяющая игрокам настраивать параметры игры (например, громкость звуков, качество графики).
- **ENTITY**: Реализована базовая система сущностей (например, зомби, растения) с соответствующей логикой поведения.
- **SHADERS**: Реализован один шейдер для свечения объектов (например, растений или зомби) при получении урона. Это добавляет визуальный эффект в ответ на повреждения, улучшая игровую атмосферу.
- **БАЗА**: Реализована основа игры, включая базовые механики и логику взаимодействия с объектами, как растения и зомби.

## В планах:
- **Добавление новых растений**: Больше вариантов растений с новыми механиками.
- **Новые типы зомби**: Уникальные зомби с особыми характеристиками и поведением.
- **Новые уровни**: Разнообразие уровней с новыми картами и сложностью.
- **Дополнительные механики**: Улучшение текущих механик и добавление новых элементов для улучшения игрового процесса.
- **Поддержка модов**: В будущем будет реализована система модов, позволяющая игрокам добавлять новый контент и изменять игру.

## Стек технологий:
- **Язык**: Java
- **Графика**: 2D
- **Звуки**: Используются звуковые файлы для эффектов.
- **Система сборки**: Gradle (настраивается вручную)
- **Шейдеры**: Используются для визуальных эффектов.

## Запуск игры:
1. Клонируйте репозиторий.
2. Настройте Gradle (если используете Eclipse).
3. Скомпилируйте и запустите проект с помощью IDE (Eclipse или Visual Studio Code).
