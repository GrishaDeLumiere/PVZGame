# PVZ PLUS

**PVZ PLUS** — это клон культовой игры **Plants vs. Zombies**, полностью реализованный на **Java**. Проект изначально создавался с акцентом на модульность и расширяемость, чтобы поддерживать модификации и новые механики, растения, зомби и уровни. Игра разрабатывалась с использованием **Gradle** и запускалась в средах **Eclipse** или **Visual Studio Code**.

> ⚠️ **Внимание:** проект **заброшен**, разработка больше не ведётся, никаких новых обновлений и планов по его развитию нет.

## О проекте

**PVZ PLUS** предлагал классический геймплей tower-defense с защитой сада от волн зомби. Включал локализацию, визуальные эффекты через шейдеры и гибкую систему настроек, но в текущем состоянии проект не поддерживается и не планируется к дальнейшему развитию.

## Основные возможности (в исходной версии)

* **Графический интерфейс (GUI)**: экраны меню, альманаха, настроек и уровней.
* **Шрифты и текст**: поддержка кастомных шрифтов через `FontManager` и `FontTT`.
* **Уровни и геймплей**: система уровней (`Level`, `LawnGrid`, `WaveSystem`) с генерацией волн зомби.
* **Звуковое сопровождение**: музыка и эффекты через `OpenALManager` и `SoundEffectManager`.
* **Текстуры и анимации**: 2D-графика и анимации (`TextureManager`, `GIFLoader`, `AnimatedObject`).
* **Локализация**: поддержка нескольких языков через `Localization`.
* **Сущности**: растения, зомби, снаряды и газонокосилки.
* **Шейдеры**: эффекты свечения (`GlowEffect`, `ShaderManager`).

## Структура проекта

* **`effects/`**, **`entity/`**, **`font/`**, **`gui/`**, **`keys/`**, **`level/`**, **`shaders/`**, **`sound/`**, **`texture/`**, **`utils/`**
* Основные классы: `GameApp.java`, `WindowManager.java`, `MainThreadManager.java`, `SettingsManager.java`, `DebugManager.java`.

## Технологии

* **Язык**: Java
* **Графика**: 2D с текстурами и шейдерами
* **Звук**: OpenAL
* **Сборка**: Gradle
* **IDE**: Visual Studio Code, Eclipse

## Как запустить

Проект можно собрать и запустить из исходников, но **поддержка и обновления отсутствуют**:

```bash
git clone https://github.com/GrishaDeLumiere/PVZGame.git
./gradlew build
```
