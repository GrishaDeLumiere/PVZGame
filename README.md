# PVZ PLUS

**PVZ PLUS** — это клон культовой игры **Plants vs. Zombies**, полностью реализованный на **Java**. Проект создан с акцентом на модульность и расширяемость, чтобы в будущем поддерживать модификации, добавляющие новые механики, растения, зомби и уровни. Игра разрабатывается с использованием **Gradle** и поддерживает запуск в средах **Eclipse** или **Visual Studio Code**.

## О проекте

**PVZ PLUS** предлагает классический геймплей tower-defense, где игроки защищают свой сад от волн зомби, размещая растения с уникальными способностями. Проект включает современные элементы, такие как поддержка локализации, настраиваемые параметры и визуальные эффекты с использованием шейдеров. Разработка началась в **Eclipse**, но теперь ведется в **Visual Studio Code** для удобства.

## Основные возможности

- **Графический интерфейс (GUI)**: Интуитивно понятные экраны главного меню, альманаха, настроек и игровых уровней.
- **Шрифты и текст**: Поддержка кастомных шрифтов через `FontManager` и `FontTT` для отображения текста.
- **Уровни и геймплей**: Система уровней (`Level`, `LawnGrid`, `WaveSystem`) с динамической генерацией волн зомби и управлением растениями.
- **Звуковое сопровождение**: Музыка и эффекты через `OpenALManager` и `SoundEffectManager` для погружения в игру.
- **Текстуры и анимации**: Поддержка 2D-графики (`TextureManager`, `GIFLoader`) и анимаций (`Animation`, `AnimatedObject`).
- **Локализация**: Механизм (`Localization`) для поддержки нескольких языков.
- **Настройки**: Гибкая настройка параметров игры через `SettingsManager` (громкость, графика и т.д.).
- **Сущности**: Полноценная система сущностей (`Entity`, `Plant`, `EntityZombie`, `Projectile`) с логикой поведения.
- **Шейдеры**: Эффект свечения (`GlowEffect`, `ShaderManager`) для визуального отклика при уроне.
- **Управление**: Поддержка мыши (`MouseManager`) и взаимодействие с игровыми объектами.

## Структура проекта

Проект организован в модульной структуре для удобства разработки и поддержки:

- **`effects/`**: Визуальные эффекты, включая `GlowEffect.java` для шейдеров.
- **`entity/`**: Логика игровых объектов:
  - `plants/`: Классы растений, например, `PeaShooterSingle.java`, `Plant.java`.
  - `Entity.java`, `EntityZombie.java`, `Projectile.java` — базовые сущности.
  - `LawnMower.java` — газонокосилка как часть механики.
- **`font/`**: Управление шрифтами (`FontManager.java`, `FontTT.java`, `Color4f.java`).
- **`gui/`**: Экраны интерфейса (`MainMenuScreen.java`, `AlmanacScreen.java`, `LoadingScreen.java`).
- **`keys/`**: Управление вводом (`MouseManager.java`).
- **`level/`**: Логика уровней и игрового поля (`Level.java`, `LawnGrid.java`, `WaveSystem.java`).
- **`shaders/`**: Шейдеры для визуальных эффектов (`ShaderManager.java`, `ShaderProgram.java`).
- **`sound/`**: Аудиосистема (`OpenALManager.java`, `SoundEffectManager.java`, `MusicManager.java`).
- **`texture/`**: Управление текстурами (`TextureManager.java`, `GIFLoader.java`).
- **`utils/`**: Вспомогательные утилиты (`DebugUtils.java`, `TimerUtils.java`, `AnimatedObject.java`).
- **Основные классы**:
  - `GameApp.java`: Точка входа в игру.
  - `WindowManager.java`: Управление окном приложения.
  - `MainThreadManager.java`, `ThreadPoolManager.java`: Управление потоками.
  - `SettingsManager.java`: Настройки игры.
  - `DebugManager.java`: Инструменты для отладки.

## Технологии

- **Язык**: Java
- **Графика**: 2D (с использованием текстур и шейдеров)
- **Звук**: OpenAL для обработки аудиофайлов
- **Сборка**: Gradle
- **IDE**: Visual Studio Code (рекомендуется), Eclipse

## Как запустить

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/GrishaDeLumiere/PVZGame.git
   ```
2. Настройте **Gradle** в вашей IDE (инструкции в `build.gradle`).
3. Скомпилируйте и запустите проект через **Visual Studio Code** или **Eclipse**.
4. Убедитесь, что зависимости, такие как OpenAL, корректно настроены.

## Установка зависимостей

Зависимости указаны в `build.gradle`. Для сборки выполните:

```bash
./gradlew build
```
