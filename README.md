# PVZ PLUS (Java)

Это клон популярной игры **Plants vs. Zombies (PVZ)**, полностью реализованный на **Java**. В проекте реализованы основные механики игры, включая меню, звуковые эффекты, уровни, базу, зомби и растения.

## Функции, реализованные на данный момент:
- **Основное меню**: Навигация через главную страницу игры.
- **Звуковые эффекты**: Добавлены звуки для разных действий и событий в игре.
- **Уровни**: Игрок начинает с одного уровня, где защищает свою базу от зомби.
- **Зомби**: Разнообразные типы зомби, каждый с уникальными характеристиками.
- **Растения**: Включает несколько типов растений с различными возможностями для защиты от зомби.
- **База**: Защищаемая база, которая должна выжить от нападений зомби.

## В планах:
- **Добавление новых растений**: Больше вариантов растений с новыми механиками.
- **Новые типы зомби**: Уникальные зомби с особенными характеристиками и поведением.
- **Новые уровни**: Разнообразие уровней с новыми картами и сложностью.
- **Дополнительные механики**: Улучшение текущих механик, добавление новых элементов для улучшения игрового процесса.

## Стек технологий:
- **Язык**: Java
- **Графика**: 2D
- **Звуки**: Используются звуковые файлы для эффектов.

## Запуск игры:
1. Клонируйте репозиторий.
2. Скомпилируйте и запустите проект с помощью IDE или командной строки.
